# Employee Management System

An Employee Management System built using Angular and REST APIs.

## Technologies Used

- Angular 22
- TypeScript
- HTML and CSS
- Bootstrap
- REST APIs

## Development Server

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
ng serve
```

Open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify the source files.

## Building the Project

To build the project, run:

```bash
ng build
```

The compiled build output is stored in the `dist/` directory.

## Running Unit Tests

To execute unit tests, run:

```bash
ng test
```
